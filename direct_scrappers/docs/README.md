## 📝 Documentation Standards

All documentation follows these conventions:
- **README.md** files in each directory explain that directory
- **Guides** are step-by-step instructions
- **Reference** docs are technical details
- **Summaries** are project overviews

---

## 🆕 Adding New Documentation

When adding new docs:
1. **User guides** → `docs/guides/`
2. **Technical reference** → `docs/reference/`
3. **Project summaries** → `docs/summaries/`
4. **Quick access** → Keep in root (like `QUICK_REFERENCE.md`)
